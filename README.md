# Talyutin — «Посторонним можно»

Рабочий прототип портфолио: планировщик турнирного дня находится внутри кейса, но его можно открыть отдельно и сохранить как автономный HTML. Исходники статические; сборка, зависимости и серверная база данных не требуются.

## Запуск

Из корня репозитория:

```bash
python3 -m http.server 8000
```

В Windows команда может называться `py -m http.server 8000`. Затем открыть `http://localhost:8000/` в браузере. HTTP-сервер нужен для передачи выбранных параметров из встроенного планировщика в отдельную страницу. Открытие `index.html` напрямую через `file://` для этого сценария не проверялось.

## Что проверить

1. Изменить число команд (8/16), площадок (1/2) и длительность матча (45/60 минут). Таблица и время окончания должны обновляться.
2. Нажать «Унести инструмент». Он откроется в отдельной вкладке с выбранными параметрами, а на портфолио останется пустое крепление. «Вернуть на место» восстановит его.
3. В отдельной вкладке скачать CSV и автономный HTML. Открыть скачанный HTML без сети и повторить изменение параметров.
4. Проверить первый экран и таблицу на телефоне и компьютере.

Расчёт — демонстрационный: олимпийская система, начало в 10:00, 15 минут между слотами и раундами, без ввода названий команд и реальных результатов. Это не календарь текущего турнира ЯКС. Данные никуда не отправляются и не сохраняются на сервере.

Опубликованная версия на Sites была сделана из этого же прототипа, но размещена отдельно. Коммиты в этом репозитории сами по себе не обновляют публикацию.
