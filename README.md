# Талютин — «Посторонним можно»

Рабочая версия **всего портфолио** находится в [`ownsite/`](ownsite/). Это одно Node.js приложение: главная сцена, каталог и раскрытие работ, контакты, API, два действующих экрана объединённого кейса ЯрКиберСезона и отдельный планировщик турнирного дня (`/tool.html`). [Инструкция по запуску и Timeweb](ownsite/README.md).

Девять редакционных записей подготовлены в `ownsite/seed-works.mjs`. При первом запуске опубликованы объединённый ЯКС и Dashboard (`show=true`); остальные семь сохраняются в базе с `show=false` до проверки роли, материалов и права показа. Главная перенесена из проверенного предпросмотра от 29 сентября. Dashboard открывается в отдельной вкладке. Планировщик — демонстрационный расчёт, а не действующее расписание ЯКС.

Для локальной разработки: Node.js 22.13+, `cd ownsite && npm ci && npm start`; затем откройте `http://localhost:4173/`. Локально используется SQLite. Dockerfile для Timeweb требует отдельную PostgreSQL и не запускается без `DATABASE_URL`.

Корневые `index.html`, `tool.html` и `assets/` — сохранённый отдельный статический прототип. В Timeweb выбирайте директорию проекта `ownsite`, иначе будет опубликован другой срез. Ранее созданная версия на Sites развёрнута отдельно: коммиты в этом репозитории не обновляют её.
