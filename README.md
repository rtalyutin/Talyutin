# Talyutin — «Посторонним можно»

В репозитории два связанных среза портфолио:

| Путь | Содержание | Как запустить |
| --- | --- | --- |
| [`ownsite/`](ownsite/) | Серверная версия всего сайта: главная сцена, каталог, контакты, API и SQLite с `show` | `cd ownsite && npm start` (Node.js ≥22.13), затем `http://localhost:4173/` |
| Корневые `index.html`, `tool.html`, `assets/` | Отдельный статический прототип кейса с отделяемым планировщиком | `python3 -m http.server 8000`, затем `http://localhost:8000/` |

Для проверки серверной версии в **Timeweb Cloud App Platform** выберите Backend → Dockerfile, репозиторий `rtalyutin/Talyutin`, ветку `main`, путь до директории проекта `ownsite`. Команды сборки и запуска вручную не нужны; порт в Dockerfile — `4173`. Подробности и ограничения проверочного запуска — в [`ownsite/README.md`](ownsite/README.md).

Серверная версия пока показывает два проверенных входа ЯрКиберСезона. Остальные карточки и итоговая приёмка продолжаются. Локальная SQLite внутри App Platform пересоздаётся при каждом деплое; для постоянной редакционной БД нужна отдельная работа.

Статический прототип позволяет изменить число команд (8/16), площадок (1/2), длительность матча (45/60 минут), вынести планировщик в отдельную вкладку и скачать CSV или автономный HTML. Его расчёт демонстрационный: олимпийская система с началом в 10:00 и паузами по 15 минут. Это не календарь текущего турнира ЯКС.

Опубликованная версия на Sites развёрнута отдельно. Коммиты в этом репозитории сами по себе не обновляют её.
