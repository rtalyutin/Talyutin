# Роман Талютин — разработка и решение задач

Рабочий сайт находится в [`ownsite/`](ownsite/). Главная — утверждённая композиция «ТАЛЮТИН» на HTML/CSS/JS с однократной вступительной анимацией «Невозможная сборка»: 36 фрагментов, 3,5 секунды. Изображения, 3D-модели, внешние шрифты и графические библиотеки для главной не используются.

Каталог, разборы работ и контакты поступают из действующего backend. Видимость определяется `show`; новая главная не меняет публикацию записей. Сохранены прямые ссылки `/?work=…&mode=reveal`, API, [игра «Точки»](ownsite/public/tochki/) и отдельный планировщик `/tool.html`.

Старый корневой прототип, телефонная 3D-сцена, её сборщик и зависимости удалены. Отдельная копия макета больше не нужна: теперь это основная страница приложения.

## Запуск

Node.js 22.13 или новее:

```bash
cd ownsite
npm ci
npm start
```

Локальный адрес: `http://localhost:4173/`. Без remote API используется SQLite. Для Timeweb: директория проекта `ownsite`, существующий Dockerfile, порт `4173`, `PORTFOLIO_API_URL` публичного API Tg-mcp. Dockerfile требует этот URL и не подменяет недоступный backend локальными данными.

[Настройка, публикация работ и проверки](ownsite/README.md).
