# Точки — этап 1

Логическое ядро для поля 43 × 60: ход человека, ответ компьютера, проверка
занятости и границ, сдача. Запуск проверки: `cd tochki && npm test`.

**Статус:** захват, счёт, домики, контуры, штриховка и игровой экран пока не
реализованы. Этот модуль нельзя выдавать за готовую партию по ТЗ 0.3.
Следующий этап — геометрия захвата с различающими сценариями обычного контура,
пустого дома и вложенности; после неё подключается интерфейс.
