# «ПОСТОРОННИМ МОЖНО» — предпросмотр всего портфолио

Это серверная версия сайта: главная сцена, каталог, два маршрута связи, API работ и SQLite с флагом `show`. В первой проверочной сборке публичны два работающих входа ЯрКиберСезона: Mini App и сайт. Другие редакционные карточки находятся в подготовке; текст о них не означает `show=1`. Dashboard допустим в будущем списке по последнему решению Романа, но частные данные не должны попасть в публичную проекцию.

## Запуск локально

Нужен Node.js 22.13 или новее. Зависимостей для установки нет.

```bash
cd ownsite
npm start
```

Откройте `http://localhost:4173/`. `npm test` проверяет фильтрацию `show`, скрытую запись в HTML/API, отзыв постера и отсутствие контактов без переменных. БД `data/portfolio.sqlite` создаётся при первом старте и не коммитится. Две публичные записи засеваются только при отсутствии. Контакты добавляются из переменных `PUBLIC_PHONE` и `PUBLIC_EMAIL`, если они заданы и корректны. Страница не собирает заявки. VK-ссылка требует точного подтверждённого URL.

## Проверочный запуск в Timeweb Cloud App Platform

Подключите GitHub `rtalyutin/Talyutin`, ветку `main`. Тип приложения — **Backend → Dockerfile**, путь до директории проекта — `ownsite`. Dockerfile запускает Node.js 24 и слушает `0.0.0.0:4173` (`EXPOSE 4173`); команды сборки и запуска в панели отдельно задавать не нужно. В переменных приложения задайте `PUBLIC_PHONE` в формате `+7...` и `PUBLIC_EMAIL` с предоставленными владельцем контактами. Без них ссылки для связи не показываются. После деплоя проверьте главную `/`, `/api/works` (две записи), ссылки на инструменты и технический домен.

**App Platform не сохраняет локальные файлы между деплоями.** SQLite внутри контейнера годится только для такого проверочного запуска: каждое обновление пересоздаёт БД из seed и теряет внесённые в неё правки. Для постоянной редакционной БД нужен перенос слоя данных на внешнюю PostgreSQL или размещение на сервере с постоянным диском. Файл `data/portfolio.sqlite` и его WAL/SHM не добавляйте в репозиторий.

Редактировать локальную БД можно через `node scripts/set-contact.mjs <phone|telegram|email> <значение>` или SQLite-клиент; `show` по умолчанию равен `0`. Перед открытием нового кейса проверьте право показа, точную роль, содержимое и рабочий адрес. Публичные HTML, API и постеры выбирают только `show=1`; скрытый slug даёт 404 как неизвестный.
