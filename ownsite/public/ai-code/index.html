03 / РЕЗУЛЬТАТ

Результат, который
можно проверить

Вы получаете ссылку на исправленную версию согласованной части проекта

Две проверки для приёмки

  1. Согласованный сценарий работает.
  2. Джун вносит типовое изменение с обычным ревью.

Проверки относятся к согласованной части проекта. Сценарий и типовое изменение выбираются при согласовании работ.
